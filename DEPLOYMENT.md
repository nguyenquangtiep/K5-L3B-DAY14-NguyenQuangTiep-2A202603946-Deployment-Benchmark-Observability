# Deployment Information

## Public URL

https://day14-production-agent-u2m3.onrender.com

## Platform

Render — Docker Web Service + Key Value (Redis).

- Deployment method: GitHub Blueprint.
- Source directory: `06-lab-complete/`.
- Configuration file: `06-lab-complete/render.yaml`.
- Region: Singapore.
- Plan: Free.

## Test Commands

### Health Check

```bash
BASE="https://day14-production-agent-u2m3.onrender.com"

curl -i "$BASE/health"
```

Expected: HTTP 200 OK.

### Readiness Check

```bash
curl -i "$BASE/ready"
```

Expected: HTTP 200 OK.

### API Test (without authentication)

```bash
curl -i -X POST "$BASE/ask" \
  -H "Content-Type: application/json" \
  -d '{"question":"Hello"}'
```

Expected: HTTP 401 Unauthorized.

### API Test (with authentication)

```bash
read -rsp "API Key: " AGENT_API_KEY
echo

curl -i -X POST "$BASE/ask" \
  -H "X-API-Key: $AGENT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"question":"Hello"}'
```

Expected: HTTP 200 OK.

## Environment Variables Set

| Variable | Configuration |
|---|---|
| PORT | Provided by Render |
| ENVIRONMENT | production |
| REDIS_URL | Referenced from the Key Value service |
| AGENT_API_KEY | Automatically generated by Render |
| RATE_LIMIT_PER_MINUTE | 10 |
| DAILY_BUDGET_USD | 1.0 |

Secret values are managed through Render environment variables and are not committed to GitHub.
